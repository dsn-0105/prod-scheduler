## 订单明细新增「最大库存量/最小库存量」（commit eadebe6，未 push）
- 需求：订单管理中增加最大库存量、最小库存量，且订单中每一条子项目（明细行）都要有。
- 改动：
  - `defaultFields.order` 新增两个 line 级字段：`stockMax`（最大库存量）、`stockMin`（最小库存量），type=number、非必填、未锁定，插在 orderQty 与 deliveredQty 之间。
  - `ORDER_LINE_KEYS` 同步加入 `stockMax`/`stockMin`（供旧字段 level 推断）。
  - `renderOrderTable` 的 `TBL_SCHEMAS` 与行渲染在「数量」列后新增两列（空值显示为空，不显示 0）。
  - 新增迁移 `migrateOrderStockRange()`：向已保存的 `fields`/`fieldsDraft` 的 order 配置补齐两字段（插在 orderQty 后，level:'line'）；为存量订单每条 items 明细行补齐 `stockMax:''`/`stockMin:''`；在 bootstrap 中置于 `migrateOrders()` 之后调用。
- 弹窗明细行（orderItemRow）、模板/导出/导入均基于 `orderLineFields()`/fields 配置动态生成，自动带上新字段，无需额外改动。
- 版本号 bump 至 `build 2026-08-19.6`（源码占位）；语法 `node --check` 通过；已 commit `eadebe6`（未 push）。
