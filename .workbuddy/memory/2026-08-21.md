- 需求：
  1. 存在弹窗时，点击弹窗外部不要消失。
  2. 表单左右滑动条固定在页面底部，不随页面/表单滚动位移。
  3. 单元格超出行宽不换行，超出部分省略为「…」。

- 改动：
  1. 弹窗外部点击：移除 `document.addEventListener('click', ...closeFiltPop())`（筛选弹窗外部点击关闭逻辑）；`openFilter` 与 `ppOpenFilter` 的筛选面板补「取消」按钮（原只有清除/确定）；modal-bg 本身无外部点击关闭，天然满足。

  3. 单元格省略：`#content .table-wrap table td{white-space:nowrap;overflow:hidden;text-overflow:ellipsis;max-width:240px}`（限定页面主区，弹窗内明细表不受影响）；进度条列加 `max-width:100%` 防裁剪。
  4. 侧边栏折叠：sidebar 底部加 `.sidebar-collapse` 按钮（箭头 svg + 「收起」文字，hover 高亮）；`.sidebar.collapsed` 宽度 210→56px，隐藏标题文字/导航文字/徽标，箭头旋转 180°；`.sidebar.collapsed~.main{margin-left:56px}`；`toggleSidebarCollapse()` 切换并 localStorage 记忆（key: sidebarCollapsed），bootstrap 恢复；移动端（≤768px）抽屉模式覆盖为不折叠。
