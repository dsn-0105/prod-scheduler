## 修复底部固定滚动条不显示（commit 5ac6296，已部署）
- 现象：页面底部只有一条空白条，没有横向滚动条。
- 根因：`.bottom-scrollbar` 容器宽=视口全宽（left:0;right:0），但 `inner.style.width` 设成 `target.scrollWidth`（表格总宽）。表格可视宽=视口-侧栏-内边距，当表格溢出量较小时 inner 仍 < 视口宽 → 容器无溢出 → 滚动条不出现；且滚动范围与表格不一致。
- 修复：`inner 宽度 = sb.clientWidth + (target.scrollWidth - target.clientWidth)`，使滚动条可滚动范围与表格一一对应；另在 renderContent 加 requestAnimationFrame 二次校正（防字体/图片加载后宽度变化）。

- 根因：`table-layout:auto` 布局下列宽下限 = 该列最宽单元格的 min-content 宽度；td nowrap → 下限=整行内容宽。

## 修复订单管理操作栏不吸顶（commit 6f17b68，已部署）
- 现象：上一版 sticky 吸顶后，订单管理两个区块的操作栏不跟随（其他表单正常）。
- 根因：`.order-sec`（订单区块容器）有 `overflow:hidden`——CSS sticky 规则：祖先 overflow 非 visible 时，sticky 相对该祖先定位，而该容器不滚动 → 永远不吸顶。
- 修复：`.order-sec` 的 `overflow:hidden` 改为 `overflow:clip`（同按 border-radius 裁剪，但不创建滚动容器，sticky 恢复相对视口）。兼容 Chrome 90+/Firefox 81+/Safari 16+。
