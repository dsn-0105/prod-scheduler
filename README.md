# 生产排单与报表系统

面向智能低压电器（断路器）制造企业的**单文件网页版**销售订单 / 生产排产 / 交付管理系统。零依赖、纯前端实现，数据默认存于浏览器本地，可无缝升级到服务器后台。

> 当前版本：`build 2026-08-18.3`

## 功能模块

| 模块 | 说明 |
|------|------|
| 看板 | KPI 卡片（执行中订单、综合交付率、库存预警、今日排产）+ 库存快照 + 订单交付进度 |
| 产品主数据 | 断路器系列主数据：日产能(未包/包装)、规格、型号 |
| 订单管理 | 框架订单，支持多明细行（表头 + 表体），交付进度追踪 |
| 半成品库存 | 每日出入库台账，期初/入库/出库/期末/上下限/预警状态 |
| 日排产 | 备货排产（装配→内包→调试老化→半成品入库）+ 包装排产（包装→成品入库→关联订单） |
| 生产日报 | 按日期 / 周维度汇总各工序完成率 |
| 交付计划 | 按交付频率自动倒排批次排期，支持实际交付填报与差异对比 |
| 字段设置 | 用户自定义字段（新增/改名/改类型/删除），审核工作流 + 系统字段锁保护 |
| 操作日志 | 字段级变更追踪（旧值→新值），覆盖全部增删改导入导出操作 |

## 技术架构

- **零依赖**：原生 HTML + CSS + Vanilla JS，无任何框架或 CDN 引用
- **DB 异步抽象层**：`DB.get/set` 封装了 `localStorage`，预留 `API_BASE` 一行切换即可改为服务器接口
- **自研 XLSX 引擎**：纯 JS 实现 ZIP 读写 / CRC32 / DEFLATE 解压 / Excel XML 解析，零依赖导入导出 Excel
- **表格引擎**：列排序、筛选、拖拽换序、拖拽调宽、布局持久化

## 本地使用

直接用浏览器打开 `index.html` 即可，无需任何构建步骤。

## 部署到 GitHub Pages

本仓库已包含 GitHub Actions 工作流（`.github/workflows/deploy.yml`），代码推送到 `main` 分支后自动构建并发布到 GitHub Pages。

1. 在 GitHub 新建一个仓库（公开或私有均可，Pages 现已支持私有仓库）
2. 推送本仓库：
   ```bash
   git remote add origin https://github.com/<你的用户名>/<仓库名>.git
   git push -u origin main
   ```
3. 仓库 **Settings → Pages**，Source 选择 **GitHub Actions**
4. 等待 Actions 运行完成，访问 `https://<你的用户名>.github.io/<仓库名>/`

## 数据说明（重要）

当前 `API_BASE` 为空，数据通过浏览器 `localStorage` 存储，**每个用户的浏览器各自保存一份，彼此不共享**。这在单机/演示场景没问题，但 10 人团队协同需要数据互通时，须接入服务器后台：

```javascript
// 在 index.html 中把 API_BASE 填上后端地址，并取消 DB.get/set 内 fetch 调用的注释
const API_BASE = 'https://your-api.example.com/api';
```

后端只需提供简单的 key-value 接口（`GET /api/:key`、`POST /api/:key`），前端其余逻辑无需改动。完整后端部署规划见企业腾讯云（2C2G4M）方案。

## 备份与恢复

- 顶部「备份」可导出全部数据为 `.json`，「恢复」可一键还原
- 自动备份：数据变更后自动下载 `.json`（最小间隔 15 分钟），换设备 / 链接轮换后用「恢复」即可还原
- 支持按表单 / 全量导入导出 `.xlsx`，并提供必填字段标红的导入模板
